# Kaezzy App

A productivity & gamification Android application built with Jetpack Compose, Room Database, and Kotlin.

## Features
- **Home**: Highlight dashboard for tasks, balance summary, daily logs, notes, and skill library.
- **Tasks**: Priority and category-filtered task management.
- **LevelUp**: Gamification system with XP rewards, levels, streaks, and missions.
- **Money**: Spendable balance tracking and savings goals.
- **Daily Log & Notes**: Journaling and quick notes.
- **Skills**: Skill learning library with code snippets and notes.
